# Examples

- [`basic.py`](basic.py) — constructs a `Client` with default configuration
  and prints its endpoint. That's the extent of what's runnable today: the
  Python SDK is a typed stub (see [`../README.md`](../README.md)), so this
  example deliberately doesn't call any RPC method yet.

Run with `python examples/basic.py` after `pip install -e ".[dev]"`.
