# go SDK — deferred

The official Go SDK for OpenFiat has not been scaffolded yet. It is
tracked in the monorepo [ROADMAP.md](../ROADMAP.md) and will follow the same
shape as [`../rust`](../rust), [`../typescript`](../typescript), and
[`../python`](../python) once prioritized.

In the meantime, see [openfiat-specs](https://github.com/OpenFiat-org/openfiat-specs)
for the protocol this SDK will implement.
