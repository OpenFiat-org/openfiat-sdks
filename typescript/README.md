# @openfiat/sdk (TypeScript)

Official TypeScript/JavaScript SDK for the OpenFiat protocol. Part of the
[openfiat-sdks](https://github.com/OpenFiat-org/openfiat-sdks) monorepo — see
the repository root [README](../README.md) for the full monorepo layout.

```bash
pnpm add @openfiat/sdk
```

```ts
import { Client } from "@openfiat/sdk";

const client = new Client();
```

See [`examples/basic.ts`](examples/basic.ts) for a runnable example.
